# Commit Guidelines

## No AI Attribution in Commits or PRs
- Never include `Co-Authored-By` lines referencing Claude, Anthropic, or any AI
- Never include "Generated with Claude Code" or similar AI tool references
- Never include emoji markers like the robot emoji before AI tool references
- Commit messages should only attribute human authors
- PR descriptions should not reference AI tools

## Commit Message Style
- Follow existing repo conventions: short subject line, blank line, body
- Reference issue numbers with `Part of #NNNN` or `Fixes #NNNN`
- Keep PR descriptions minimal: `## Summary` with bullet points
